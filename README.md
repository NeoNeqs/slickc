## About slickc
A compiler for the slick programming language

## WebAssembly Demo

Try the live WebAssembly demo:
- Main: [https://NeoNeqs.github.io/slickc/](https://NeoNeqs.github.io/slickc/)
- Develop: [https://NeoNeqs.github.io/slickc/develop/](https://NeoNeqs.github.io/slickc/develop/)

The `main` branch deploys to the root, `develop` to `/develop/`, and tags to `/tagname/`.
